Abstract

Robot simulation and digital twins require scene representations that can be updated from real observations at the level of individual objects rather than only as whole-scene renderings. Existing 3D Gaussian Splatting methods provide efficient explicit scene representations, but their optimization is usually organized around global rendering consistency and does not explicitly yield reusable object assets for online state transfer.

DGSRSim addresses this representation-to-state gap with an object-centric 3D Gaussian pipeline that decouples movable object assets from the background field in a shared world frame. Online RGB-D observations are converted into object-level point clouds for coarse-to-fine registration and state writing. The study supports object-level reconstruction, state estimation, and simulation-side synchronization as an implementation path; robot task reliability and physical interaction metrics remain outside the current evaluation scope.

Pipeline

01

Decoupled Gaussian Modeling

Train independent Gaussian object assets and a background field from captured multi-view data, using mask-guided object/background separation.

02

Online RGB-D Observation

Capture Kinect RGB-D frames, enforce strict color-depth alignment, segment the target object, and crop a filtered object point cloud.

03

Object State Estimation

Register online object point clouds against asset-derived reference geometry using coarse-to-fine alignment and registration-quality filtering.

04

Simulation Synchronization

Convert Gaussian PLY outputs into simulation assets and write object states into LeIsaac/IsaacLab scenes.

Method Overview

Object-Level Assets

Gaussian objects are optimized as separable units so that they can be transformed, reused, and synchronized independently.

Background Separation

The background model is trained separately to reduce object residuals and improve continuity in regions affected by object occlusion.

Simulation-Oriented Conversion

The conversion path keeps only the necessary 3DGRUT-derived tools for turning Gaussian PLY outputs into mesh, USD/USDZ, and collision assets.

Mutable Real-to-Simulation Scene

Object Assets

Movable object assets can be added, removed, replaced, or rearranged without rebuilding the background representation.

Robot Assets

Robot assets such as a manipulator can be introduced into the same simulation scene and used for interaction-oriented studies.

State Updates

Online RGB-D observations estimate object states and update the corresponding virtual assets while leaving unchanged objects untouched.

Representative Results

Evaluation Scope

Rendering Quality

PSNR, SSIM, and LPIPS are used on the offline evaluation set for object-region and background-region reconstruction comparisons.

Pose Estimation

Object-state estimation is evaluated on the current online test sequences and compared with classical and strong registration baselines.

Synchronization Scope

The average stage-wise cost is approximately 73 ms/frame under the reported configuration, supporting online interaction potential without claiming task-level reliability.

  • Fig. 8 in the manuscript is a supplementary load diagnostic, not a complete per-object, per-frame runtime scaling law.
  • The minimal pick demonstration records an interface chain; it is not used as a grasp-success or robot-task reliability metric.
  • Physical contact stability, collision penetration, and long-horizon closed-loop manipulation require independent task-level protocols.
